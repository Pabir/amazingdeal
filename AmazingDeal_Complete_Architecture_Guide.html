2. Multi-Tenancy Engine & Request Lifecycle

AmazingDeal uses the Discriminator Column Pattern with automated Hibernate session filtering. Every multi-tenant entity stores a tenant_id UUID column.

How Request Isolation Works (Step-by-Step):

  1. Subdomain Extraction (TenantResolver.java): Inspects the HTTP Host header. E.g., for sharma.amazingdeal.co.in, it extracts sharma. Fallbacks check ?store=sharma or header X-Tenant-ID.
  2. Tenant Validation & Context Binding (TenantFilter.java): Resolves the tenant from database. If active, binds the UUID to ThreadLocal TenantContext.setTenantId(tenant.getId()).
  3. Hibernate Session Injection: The filter enables Hibernate's session filter: 
    session.enableFilter("tenantFilter").setParameter("tenantId", tenantId);
    Every JPA query subsequently executed by repositories automatically appends WHERE tenant_id = 'xxxx'. It is mathematically impossible to leak data across stores.
  4. Audit Assignment (TenantAwareEntity.java): When creating records, @PrePersist automatically reads TenantContext.getTenantId() and injects it before the SQL INSERT statement runs.
  5. Thread Cleanup: A finally block executes TenantContext.clear() to prevent ThreadLocal memory leakage across thread pool executions.

4. Authentication, Security & RBAC Engine

AmazingDeal enforces defense-in-depth across three separate user roles using stateless JJWT:

  • ROLE_MERCHANT: Store owners administering products, orders, POS billing, and GST reports.
  • ROLE_CUSTOMER: Shoppers logging in via Firebase Authentication (Google 1-Tap or Mobile SMS OTP). Mandatory at checkout to prevent guest order fraud.
  • ROLE_SUPERADMIN: Master platform operators overseeing stores, platform revenue, and server health.
Mandatory Customer Checkout Guard: Both frontend (CartDrawer.tsx, CheckoutModal.tsx) and backend (StorefrontController.placeOrder) strictly validate customer identity. Unauthenticated requests are rejected with HTTP 401 Unauthorized.

5. AI Product Studio & Vision Pipeline

Merchants can snap a single packaging photo. AiCatalogGeneratorService.java calls Google Gemini 3.8 Flash (with automatic OpenAI GPT-4o-mini fallback) to extract:

  • Clean Title, Brand Name, and Subcategory
  • Recommended Selling Price and Compare MRP
  • Detected Barcode / EAN number
  • HSN / SAC Code and matching Indian GST tax slab (0%, 5%, 12%, 18%, 28%)
  • 360° Studio Enhancer: Generates 4 synthetic angles (0° Front Hero, 45° Perspective, 90° Side Profile, Macro Detail) displayed in an interactive touch/mouse turntable scrubber.

6. Indian Payment Stack & Hardware Printing

  1. Direct UPI Dynamic QR (0% MDR): Formats NPCI standard deep link: upi://pay?pa=store@okaxis&pn=StoreName&am=150.00&tn=ORD-1001&cu=INR Generates instant QR code via Google ZXing library. Customers tap to open GPay, PhonePe, or Paytm.
  2. Razorpay BYOK: Merchants can plug in their own Razorpay Key ID and Secret. Backends enforce strict cryptographic HMAC-SHA256 signature verification with zero mock bypasses.
  3. Vyapar POS Counter Billing (PosCounter.tsx): High-speed billing with barcode scanner support, hotkeys (F2 New Bill, F4 Quick Cash, F8 Clear), and automated Cash Change Calculator (₹100, ₹200, ₹500 rupee presets).
  4. Thermal Printing: Native 58mm and 80mm ESC/POS monospace receipt formatting.
  5. Isolated Print Engine (printInvoices.ts): Renders A4 GST Tax Invoices in a dedicated hidden iframe, completely eliminating browser modal clipping and ensuring zero blank sheets on printers like Epson L3310.
  6. GSTR-1 Excel Engine (gstExport.ts): Generates 4-sheet Microsoft Excel XML Workbooks (.xls) for Master Sales Register, Table 4 (B2B), Table 7 (B2C), and Table 12 (HSN Summary).

7. Logistics Engine & Delivery Fleet

  • Shiprocket Domestic Courier (BYOK): Automated AWB generation, shipping labels, and live serviceability check across 29,000+ Indian pincodes.
  • Store Rider Dispatch: Hyperlocal radius calculation, whitelisted pincodes, delivery time slot selection ("Today Evening", "Rush Express 60-mins"), and 1-tap WhatsApp dispatch link with customer address, Google Maps GPS coordinates, and cash-to-collect instructions.

8. Superadmin Master Operations Suite

Accessed at /superadmin and housed inside frontend-admin:

  • JPA Dynamic Specifications: Uses JpaSpecificationExecutor<T> and Criteria API predicates, completely eliminating untyped null parameter JDBC crashes in PostgreSQL.
  • Platform KPIs: Live metrics for Active/Suspended Merchants, Customers, Orders, Platform GMV, and SaaS Revenue.
  • 1-Click Store Impersonation: Generates scoped merchant JWTs allowing superadmins to inspect any store's dashboard with a sticky top return banner.
  • JVM Memory Meter: Real-time telemetry of committed heap, active memory, and container headroom.

10. Cloud DevOps & Zero-Cost Infrastructure Playbook

1. Production Deployment Topology

  • Database: Neon Serverless PostgreSQL 16 (AWS us-east-2). Automatically scales and sleeps when inactive to maintain ₹0 hosting cost.
  • Backend Web Service: Render Free Tier (Docker runtime, Java 21 LTS). Paired with an automated Keep-Alive ping (Cron-job.org / UptimeRobot) pinging /api/v1/health every 10 minutes to eliminate cold starts.
  • Frontend Static Assets: Cloudflare Pages / Workers. Unlimited bandwidth, deployed via wrangler deploy with custom routes for admin.amazingdeal.co.in and *.amazingdeal.co.in.
  • Object Storage: Cloudflare R2 S3-compatible bucket (media.amazingdeal.co.in) with 10 GB free storage and 0 egress fees.

2. Alternative OCI Always-Free Stack

The repository includes turnkey configuration for an Oracle Cloud Always-Free ARM VM (4 OCPUs, 24 GB RAM, 200 GB SSD) via docker-compose.oci.yml: 

# Start complete local stack on OCI VM
docker compose -f docker-compose.oci.yml up -d --build

Includes local PostgreSQL 16 container, Spring Boot backend container, and Caddy container providing automated Let's Encrypt SSL certificates for api.amazingdeal.co.in.
